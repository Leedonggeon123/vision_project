스크린샷 아래에 놓는 번호 설명 한 줄입니다. 번호 배지 + 굵은 단어 + 설명 문장.

**제공할 것:** 번호, 강조 단어, 설명 문장(한두 문장).

- 왼쪽에 `NumberBadge`(최소 폭 32px, 위로 정렬), 오른쪽에 글자. 사이 간격 `space-12`.
- 글자는 `sub`(15px, 줄간격 1.55) `muted`. 강조 단어만 `legend-key` `ink`.
- 여러 줄을 `grid-template-columns: repeat(auto-fit, minmax(min(100%, 420px), 1fr))`, 간격 `12px 28px`로 늘어놓습니다.

**하지 않기:** 배지 없는 항목, 번호 순서를 건너뛰기, 설명에 `OK`/`NG` 없이 색 이름만 쓰기.
