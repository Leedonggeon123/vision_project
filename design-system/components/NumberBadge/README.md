스크린샷 위에 올리는 주황 번호 알약입니다. 아래 범례의 같은 번호와 짝을 이룹니다.

**제공할 것:** 숫자 또는 `C2` 같은 짧은 문자(최대 3자), 스크린샷 안의 위치(`left`, `top` 백분율).

- 높이 24px, `radius-pill`, 바탕 `amber`, 글자 `on-amber` 12px 700.
- 스크린샷 위에서는 `badge-ring`을 두릅니다. 범례 안에서는 링 없이 씁니다.
- 위치는 `left: x%; top: y%`에 `transform: translate(-50%, -50%)`로 가운데를 맞춥니다.
- 600px 이하에서는 18px.

**하지 않기:** 두 글자를 넘는 설명 글, 다른 색 배지, 한 화면에 같은 번호 두 번.
