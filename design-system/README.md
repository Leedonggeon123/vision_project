어두운 바탕에 주황 한 가지 포인트를 쓰는, 공장 검사 화면용 가이드 문서 스타일입니다. 한국어 설명 문서, 화면 스크린샷 + 번호 범례를 만들 때 이 규칙을 따릅니다.

## 말투와 글쓰기

- 한국어로, 쉬운 말로 씁니다. "금속 너트 이상탐지 프로그램의 화면 4개입니다."처럼 무엇인지 먼저 말합니다.
- 존댓말(`~입니다`, `~합니다`)로 끝냅니다. 이모지는 쓰지 않습니다.
- 제목은 짧은 명사구(`1. 실시간 검사`, `3. 통계 대시보드`). 번호를 붙여 순서를 보여 줍니다.
- 설명은 `lead` 한 문단으로 끝냅니다. 길게 늘이지 않습니다.
- 판정은 항상 글자로 씁니다: `OK`, `NG`. 색만으로 알리지 않습니다.

## 색

- 바탕은 `bg`, 그 위 카드는 `surface`, 테두리는 `border`. 그림자 대신 테두리로 층을 나눕니다.
- 제목과 강조는 `ink`, 설명은 `muted`.
- `amber`는 포인트 하나뿐입니다. 번호 배지, 호버/포커스 테두리에만 씁니다. 면적을 넓게 칠하지 않습니다.
- `ok`(초록)와 `ng`(빨강)는 판정 표시에만 씁니다. 장식에 쓰지 않습니다. 둘 다 `OK`/`NG` 글자와 함께 둡니다.
- 모든 화면은 다크 한 가지입니다. 라이트 테마는 없습니다.

## 글꼴과 크기

- 글꼴은 `Noto Sans KR`(400, 500, 700)을 Google Fonts에서 불러옵니다. 실패하면 `Malgun Gothic`, `Segoe UI`, 시스템 글꼴 순입니다.
- 페이지 제목 `title`(36px, 굵게), 섹션 제목 `section`(26px, 굵게), 소개 `lead`, 설명 `sub`, 범례 `legend-key`.
- 제목은 `text-wrap: balance`로 줄바꿈을 고릅니다. 소개 문장 폭은 `65ch` 이하.

## 모양과 간격

- 페이지는 가운데 정렬된 `main`(최대 1100px). 섹션 사이는 `space-56`, 좌우 여백은 최소 `space-16`.
- 내비게이션 칩은 `radius-sm`, 스크린샷 프레임은 `radius-lg`, 번호 배지는 `radius-pill`.
- 포커스는 바깥선을 지우는 대신 `amber` 테두리로 바꿉니다. 칩은 호버와 키보드 포커스에서 같은 모양입니다.
- 모션은 쓰지 않습니다.

## 스크린샷과 번호 범례

화면 설명 문서의 기본 구조입니다. 컴포넌트 `ScreenshotFrame`, `NumberBadge`, `LegendRow`, `NavChip`을 보세요.

1. 섹션마다 스크린샷 하나를 `ScreenshotFrame`에 넣습니다.
2. 스크린샷 위의 설명할 자리에 `NumberBadge`를 올립니다. 위치는 백분율 좌표로 정하고 `badge-ring`을 둘러 사진 위에서도 보이게 합니다.
3. 프레임 아래에 같은 번호의 `LegendRow`를 2열 이상 격자로 늘어놓습니다. 열 최소 폭은 420px, 좁은 화면에서는 한 열.
4. 화면마다 반복되는 공통 부분은 `C2`, `C3`처럼 `C` 번호를 붙여 구분하고, 소개 문단에서 한 번만 설명합니다.
5. 페이지 위쪽에 `NavChip`으로 섹션 이동 링크를 둡니다.
6. 좁은 화면(600px 이하)에서는 배지를 18px로 줄입니다.

## 쓰지 않는 것

- 보라·파랑 그라데이션, 이모지 장식, 왼쪽 색 띠 카드.
- `amber` 외의 포인트 색, 배지 바탕에 흰 글자.
- 로고가 없으므로 이름은 글자로만 씁니다.
