# AI 비전 검사 WPF 앱

금속 너트 이상탐지(PatchCore) 결과를 보여 주는 WPF 프로그램입니다.
화면만 담당하고, 검사는 `engine\infer_engine.py`(Python)가 합니다.

## 실행

```powershell
cd C:\Users\AIOT\vision_project\app\VisionInspector
dotnet run
```

- 켜지면 엔진도 같이 켜집니다. 아래쪽 상태 표시줄에 **"엔진 준비 완료"** 가 뜨면 검사할 수 있습니다.
  (보통 약 10초. 설치 직후 첫 실행은 수 분 걸릴 수 있음)
- VS Code 에서 `app\VisionInspector` 폴더를 열고 터미널에서 `dotnet run` 해도 됩니다.

## 화면 4개

| 화면 | 하는 일 |
|---|---|
| 실시간 검사 | 웹캠 미리보기, 자동 간격 검사, 파일 1장 검사, 폴더 연속 검사 |
| 이력 조회 | 판정·기간으로 검색, 줄을 누르면 원본과 히트맵 표시 |
| 통계 대시보드 | OK/NG 비율, 날짜별 건수, 최근 점수 추이 (LiveCharts2) |
| 설정 | OK/NG 기준값, 자동 검사 간격, 웹캠 번호, 엔진 경로 |

## 폴더 구조

```
VisionInspector\
  Models\        검사 기록, 엔진 응답, 설정
  Services\      EngineService(엔진 실행·통신) CameraService(웹캠) DbService(SQLite)
                 InspectionService(검사→판정→저장) SettingsService
  ViewModels\    Main / LiveInspection / History / Dashboard / Settings
  Views\         화면(XAML) 4개
  Converters\    색·이미지 변환
```

## 동작 방식

- 엔진과는 표준 입출력으로 주고받습니다. 사진 경로 한 줄을 보내면 JSON 한 줄이 돌아옵니다.
- **OK/NG 판정은 WPF 가** 합니다. 엔진이 준 점수가 설정의 기준값 이상이면 NG.
  (기준값은 설정 화면에서 바꾸면 바로 적용됩니다)
- 이력은 `inspection.db`(SQLite), 원본은 `captures\`, 히트맵은 `results\` 에 저장됩니다.
- 설정은 `app\settings.json`, 오류 기록은 `app\crash.log` 에 남습니다.

## 웹캠 설정 (설정 화면 > 웹캠 촬영 영역)

- 모델은 **너트가 꽉 찬 정사각형 사진**으로 학습했습니다. 웹캠 화면에는 핸드폰 테두리와 배경이 같이 찍히므로,
  **가운데 정사각형만 잘라서** 검사합니다. 미리보기의 주황 네모 안쪽만 검사됩니다.
- 핸드폰 화면의 너트 사진이 주황 네모를 꽉 채우도록 웹캠과 핸드폰 위치를 맞추세요.

## 시연 팁

- 웹캠이 없거나 불안정하면 **[폴더 연속 검사]** 로 `data\...\test\` 의 사진을 순서대로 검사할 수 있습니다.
  (설정의 자동 검사 간격이 사진 사이 간격이 됩니다)
- 시연 사진은 학습에 쓰지 않은 `test` 폴더에서 고르세요.
- 시연 전에 한 번 켜서 엔진 시작 시간을 확인해 두세요.
